# Demo photos

Put your demo images in this folder and list their filenames in `list.json`.

- **list.json** — JSON array of image filenames, in the order you want (e.g. `["Beach.jpg", "Mountain.jpg", "City.jpg"]`).
- **Tags** — The tag shown in the game is the **filename without the extension** (e.g. `Beach.jpg` → tag **Beach**). Use clear filenames like `Sunset.jpg`, `Forest.png`, etc.
- Use 2–25 images. Supported formats: jpg, png, gif, webp, etc.

Example `list.json`:

```json
["Beach.jpg", "Mountain.jpg", "City.jpg", "Laptop.jpg", "Coast.jpg"]
```

Add your image files with these names (or edit the list to match your filenames).
